# رشاقتي (Rashaqati) - دليلك اليومي لحياة صحية ومتوازنة

موقع عربي شامل للتوعية باللياقة البدنية، التغذية السليمة، ومراجعات المكملات الغذائية مع ميزة استقبال الاستفسارات عبر نماذج Netlify Forms.

## المميزات
- تصميم عصري سريع ومتجاوب بالكامل باللغة العربية (RTL).
- مقالات متخصصة في الصيام المتقطع، التمارين المنزلية، التغذية الاقتصادية، وإدارة التوتر.
- قسم مراجعات مكملات غذائية مع بطاقة منتج تفاعلية برابط مباشر.
- قسم تواصل واستفسارات مع حماية من السبام عبر Netlify Forms.
- إعدادات أمان وتحسين سرعة التخزين المؤقت عبر `netlify.toml`.

## التشغيل المحلي
يمكن تشغيل الموقع محلياً عبر Netlify CLI:
```bash
netlify dev --port 8889
```
أو عبر أي خادم ويب ثابت (مثل `npx serve .`).
